# Wemoguen.cl

## 🧩 Descripción

Plataforma e-commerce desarrollada para gestionar productos y ventas online.

## 🚀 Tecnologías

* TypeScript
* Frontend moderno
* Backend (PHP)

## ⚙️ Funcionalidades

* Catálogo de productos
* Carrito de compras
* Integración con pagos

## 🌐 Demo

https://shopwemoguen-cl.vercel.app

## 💡 Problema que resuelve

Permite digitalizar ventas y mejorar el alcance comercial del negocio.
